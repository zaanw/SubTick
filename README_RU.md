# SubTick

Экспериментальный Windows-мод для Geometry Dash на Geode. Он получает временные метки нажатий и размещает их внутри фактических физических обновлений игрока.

## Цель

SubTick забирает события PlayerButtonCommand с временными метками Geode, сопоставляет их с реальными физическими шагами игрока и разделяет шаг в точке нажатия.

## Поддерживаемая конфигурация

- Geometry Dash 2.2081 для Windows
- Geode SDK 5.8.2
- C++23
- Буфер на 2048 событий

Другие версии игры и платформы пока не заявлены как поддерживаемые.

## Режимы

- **Compatibility Subtick** — режим по умолчанию. Разделяет только те состояния, где игрок допускает сегментированное обновление по текущим правилам совместимости.
- **Exact Subtick** — пытается разделять каждый физический шаг, содержащий нажатие. Экспериментальный режим: порядок столкновений и физики может отличаться от ванильного.

SubTick не повышает частоту физики игры и не устраняет задержки опроса устройства, рендеринга или вывода изображения на экран.

## Проверка

Автоматические тесты проверяют порядок событий, одинаковые временные метки, границы физических шагов, опоздавшие события, неверное время, переполнение буфера и независимость от FPS от 15 до 3000.

Успешная сборка в CI подтверждает компиляцию, но не заменяет проверку непосредственно в Geometry Dash. Результаты живого игрового тестирования и заявления о снижении полной задержки пока отсутствуют.

## Безопасность

- Не запускай SubTick вместе с другими модами тайминга ввода.
- При неверных временных метках, сильном дрейфе часов или переполнении буфера включается штатный путь обработки ввода.
- Пауза, выход с уровня, завершение и перезапуск уровня сбрасывают планировщик.
- Основной таймлайн использует фиксированный буфер без выделения памяти при обычной работе.
